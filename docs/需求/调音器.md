# TunePick 调音器需求

基准：v1.1.0 / 2026-11-11

## 1. 产品定位

TunePick 是打开网页就能用的吉他调音器。用户拨一根弦，页面用麦克风听琴声，告诉用户这根弦偏高还是偏低、差多少，直到调准。

- 面向六弦吉他的标准调弦：E2、A2、D3、G3、B3、E4。
- 手机竖屏优先，电脑浏览器同样可用。
- 不需要安装、注册和联网服务。琴声只在本机分析，不上传、不保存。

## 2. 使用流程

1. 打开页面，点「开始调音」，在浏览器弹窗里允许使用麦克风。
2. 拨一根弦。页面显示当前音名、频率和偏差，指针指出偏低还是偏高。
3. 按提示拧弦钮，指针回到正中、界面变绿就是调准了。
4. 换下一根弦，重复第 2、3 步。
5. 调完点「停止」，或者直接离开页面。

## 3. 功能

### 3.1 拾音

- 点「开始调音」后才请求麦克风权限。页面不会自己打开麦克风。
- 拾音时关闭浏览器的降噪、回声消除和自动增益。这些处理是为通话设计的，会把持续的琴声削弱。
- 拾音期间按钮变成「停止」，点它立即放开麦克风。
- 页面切到后台时自动放开麦克风；回到前台时自动接着听。
- 拾音期间保持屏幕常亮（浏览器不支持时按系统设置熄屏）。
- 麦克风中途断开时回到未开始状态，并提示「麦克风断开了。点「开始调音」重新连接。」

### 3.2 读数

页面上方显示三项读数：

| 读数 | 内容 | 格式 |
|---|---|---|
| 音名 | 当前琴声最接近的半音，带升号和八度 | `E2`、`F♯2` |
| 频率 | 当前琴声的基频 | 一位小数，单位 Hz |
| 偏差 | 当前琴声相对目标弦的偏差 | 整数，单位音分，带正负号；负数偏低，正数偏高 |

- 音名显示的是实际听到的音，不是目标弦。例如 6 弦松到了 D2，音名显示 D2，偏差显示 −200。
- 琴声停止后读数保留约 1.2 秒并调暗，之后清空。
- 没有读数时，音名和偏差显示占位线，频率显示「–」。

### 3.3 仪表盘

- 页面中央是指针式仪表盘，刻度范围是 −50 到 +50 音分，正中是 0。
- 指针偏左表示偏低，偏右表示偏高。偏差超出刻度范围时指针停在端点。
- 没有读数时指针停在最左端。
- 刻度正中有一段调准区，宽度是 ±5 音分。

### 3.4 颜色

| 状态 | 颜色 |
|---|---|
| 调准 | 绿色 |
| 偏低或偏高 | 琥珀色（橙色） |
| 没有读数 | 灰色 |

音名、指针、偏差数字和目标弦都跟随这个颜色。调准时整屏上方泛绿光，眼睛盯着弦钮时用余光也能看到。

### 3.5 调准判定

- 偏差进入 ±5 音分时判定为调准。
- 调准后偏差超过 ±6 音分才退出调准状态。退出门限比进入门限宽 1 音分，避免读数停在 5 音分附近时界面在两种颜色之间闪烁。

### 3.6 目标弦

页面下方画着一小段指板，六根弦从左到右是 6 弦到 1 弦，粗细和实物一致，下面标出各自的标准音。

- **自动识别**（默认）：页面把琴声归到音分距离最近的那根弦，以它为目标弦。
- **手动选弦**：点某根弦，目标弦固定为它，不管听到的音离哪根弦更近。弦跑调很远、自动识别会认错弦时用这个模式。
- 点「自动识别」回到自动模式。
- 目标弦的音名框有描边；手动选中的弦音名框是实心的。

### 3.7 参考音

- 点某根弦时播放它的标准音，时长 2 秒，像拨弦一样渐弱。频率按当前的 A4 基准计算。
- 参考音播放期间暂停拾音，避免调音器听到自己的声音。
- 不需要先点「开始调音」，任何时候点弦都能听参考音。
- 设置里可以关掉「点琴弦时播放参考音」，关掉后点弦只选弦。

### 3.8 设置

点右上角的「A4 = 440 Hz」打开设置。

| 设置项 | 范围 | 默认值 |
|---|---|---|
| 基准音 A4 | 415 到 466 Hz，每次调 1 Hz | 440 Hz |
| 点琴弦时播放参考音 | 开 / 关 | 开 |

- 「恢复 440 Hz」一键回到默认基准。
- 设置保存在本机浏览器里，下次打开沿用。
- 设置面板底部显示版本号和构建号，旁边是「更新到最新版」按钮。点它手动检查新版本：有就下载并刷新，已经是最新版会提示。

### 3.9 状态提示

仪表盘下方有一行文字提示当前该做什么：

| 情况 | 提示 |
|---|---|
| 还没开始 | 点「开始调音」，然后拨一根弦 |
| 正在请求麦克风 | 正在打开麦克风… |
| 在听，没有琴声（自动识别） | 拨一根弦 |
| 在听，没有琴声（手动选了 6 弦） | 拨 6 弦 |
| 偏低，在刻度范围内 | 6 弦偏低，拧紧一点 |
| 偏低，超出刻度范围 | 6 弦偏低很多，继续拧紧 |
| 偏高，在刻度范围内 | 6 弦偏高，放松一点 |
| 偏高，超出刻度范围 | 6 弦偏高很多，继续放松 |
| 调准 | 6 弦调准了 |
| 正在播放参考音 | 正在播放 6 弦的参考音 E2 |

### 3.10 麦克风打不开时的提示

提示显示在「开始调音」按钮上方，按钮保持可点，用户处理后可以直接重试。

| 原因 | 提示 |
|---|---|
| 用户或系统拒绝了权限 | 麦克风权限被拒绝，听不到琴声。请在浏览器的网站设置里允许使用麦克风，再点「开始调音」。 |
| 没有麦克风 | 没有找到麦克风。接好麦克风后再点「开始调音」。 |
| 麦克风被占用 | 麦克风打不开，可能正被其他应用占用。关掉占用它的应用后再点「开始调音」。 |
| 页面不是 HTTPS | 当前地址不是 HTTPS，浏览器不允许使用麦克风。请改用 https 地址打开。 |
| 浏览器不支持 | 这个浏览器不支持麦克风采集。请换用新版的 Chrome、Safari、Edge 或 Firefox。 |
| 其他错误 | 麦克风打开失败。（后面附浏览器给出的原因） |

### 3.11 安装和离线

- 页面是 PWA，可以添加到手机主屏幕或安装到电脑，像应用一样全屏打开。
- 打开过一次后，没有网络也能使用。
- 发布新版本后，页面弹窗说明更新内容，点「立即更新」才刷新页面；调音过程中不弹，停下来再提示。点「稍后」后，本次使用期间不再自动弹。
- 升级完成的下一次打开，顶部短暂提示「已更新到 vX.Y.Z」。

## 4. 质量要求

| 方面 | 要求 |
|---|---|
| 精度 | 标准六弦的基频识别误差小于 1 音分（稳定的单音）；有环境噪声时小于 3 音分 |
| 稳定 | 持续的音，读数抖动不超过 ±1 音分；单帧误检不会让指针或目标弦跳动 |
| 换弦 | 从一根弦换到另一根弦，250 毫秒内跟上；换弦过程中指针不会甩到端点 |
| 抗噪 | 说话声、环境噪声不产生读数 |
| 隐私 | 琴声只在浏览器里分析，页面不发出任何包含音频的请求 |
| 部署 | 纯静态文件，没有后端 |
| 兼容 | 近两年的 Chrome、Edge、Safari（含 iOS）、Firefox |
| 屏幕 | 手机竖屏优先；高度 550 像素以上的屏幕不用滚动就能看到全部内容 |
| 无障碍 | 所有操作可以用键盘完成，焦点可见；状态提示能被读屏软件读出；系统开了「减弱动态效果」时不播放装饰动画 |

## 5. 验收标准

1. 对着六根弦的标准音，页面显示正确的音名、频率，偏差在 ±1 音分以内，界面变绿并提示调准。
2. 偏差在 ±5 音分以内时提示调准，超出时显示琥珀色并提示拧紧或放松的方向。
3. 连续拨不同的弦，目标弦和读数稳定跟随，不来回跳。
4. 拒绝麦克风权限后，页面显示 3.10 里的提示，并且可以重试。
5. 把构建产物放到任意静态服务器上就能使用。

## 6. 不在范围内

- 其他调弦法（Drop D、开放调弦等）和其他乐器。
- 节拍器、和弦识别、录音。
- 多语言界面。界面语言是简体中文。
